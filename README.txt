WIZARD'S CASTLE — iPad build

Files:
  index.html              Game
  manifest.webmanifest    Home-screen/PWA metadata
  sw.js                   Offline cache

QUICK TEST
Open index.html in a desktop browser. The game works as a normal webpage.

IPAD INSTALL
To get a true Home Screen web app with offline caching, serve this folder over HTTPS
(e.g. GitHub Pages or another static web host), open the site in Safari on the iPad,
tap Share > Add to Home Screen.

Controls
Use the large touch buttons or type commands. SAVE stores the current game in the
browser's local storage. RESUME restores it.

This is a recreation based on the documented historical rules of Joseph R. Power's
Wizard's Castle, rather than an Amiga emulator.
