The Wizard’s Castle

An iPhone/iPad-friendly recreation of Joseph R. Power’s The Wizard’s Castle, the classic BASIC dungeon-crawling adventure originally written around 1980.

About

This project recreates The Wizard’s Castle in a form that runs easily on modern devices while preserving the character of the original game.

The Game

The Wizard’s Castle is an early text-based dungeon crawler set inside an enormous 8 × 8 × 8 castle containing 512 rooms.

The wizard Zot has hidden his legendary Orb of Power somewhere within the castle. The player explores its eight levels searching for the Orb while encountering monsters, treasure, traps, strange rooms, magical objects, and the Runestaff needed to complete the quest.

Although the presentation is primarily text, the game includes a simple map of the castle’s rooms. Randomized contents make each expedition different.

Players can choose to adventure as an:

* Elf
* Dwarf
* Man
* Hobbit

Character attributes, equipment, exploration, combat, treasure hunting, and resource management form the core of the game.

This Version

This recreation is designed primarily for iPhone and iPad Safari while deliberately retaining the appearance and feel of the old computer version.

It features:

* Black-and-white terminal presentation
* 8 × 8 × 8 castle
* Randomized dungeon contents
* Text commands
* Large touch controls
* Keyboard support
* Map display
* Character statistics and inventory
* Monsters and combat
* Treasure
* Flares and lamp
* Runestaff and Orb quest
* Local save/resume
* Progressive Web App support
* Offline play after installation

The interface is intentionally simple. This isn’t intended to turn The Wizard’s Castle into a modern graphical RPG. The old terminal interface is part of the experience.

Playing on iPhone or iPad

Once the game is hosted with GitHub Pages:

1. Open the game in Safari.
2. Tap the Share button.
3. Choose Add to Home Screen.
4. Launch The Wizard’s Castle from its new icon.

After installation it behaves much like a standalone app and can work offline.

Controls

Movement can be performed with the large on-screen N, S, E, W, UP, and DOWN buttons.

Additional controls provide quick access to commands such as:

MAP · INV · FLARE · LAMP · OPEN · GAZE · ATTACK · READ · DRINK · SAVE

Commands can also be entered manually using the command line.

Accuracy

This is currently a recreation rather than a byte-for-byte port of the original BASIC program.

The project is being developed toward increasingly faithful reproduction of the original game’s rules, behavior, messages, dungeon generation, and atmosphere while remaining comfortable to use on a touchscreen.

Where there’s a choice between flashy modernization and preserving the character of the original game, the original wins.

Project Status

Work in progress.

The initial playable version is being tested on iPhone and iPad. Mechanics and presentation will continue to be compared against surviving documentation and implementations of the original Wizard’s Castle.
